# Evaluation evidence plan

- Identify the original FER2013 class mapping and data permissions.
- Record model, preprocessing, dataset provenance and held-out data splits.
- Measure identity false-match and false-non-match rates separately from expression-classification metrics.
- Record per-class confusion matrices, test conditions and demographic/fairness limitations where lawful data permits.
- Test latency, camera faults and accessible manual check-in.
- Do not upload photos, biometric templates, recordings or participant-level outcomes.
