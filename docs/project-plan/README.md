# Work breakdown structure and sprint control

The detailed schedule and risk links are in [wbs-tasks.csv](wbs-tasks.csv).

- Each issue should use a WBS ID, named owner, independent reviewer, dependency, linked risk and acceptance evidence.
- Daily asynchronous updates and two scheduled live team meetings each week.
- Review the risk register weekly; use phase gates G0–G4 for decisions.
- These planning documents do not claim completed tests or implementation.
